Quick Start

1
Add files

Click Choose .pl files or drop PipeCAD project files on the box. You can add more at any time. Each file shows its project, units, PipeCAD version, floors and detectors.

2
Order them

Use ↑ and ↓ to set the order, and × to remove a file. The file marked header supplies the project-wide settings. Floors from the other files follow in list order.

3
Review

The summary shows the merged floors and detectors. Any name that clashed with an earlier file is listed under Renamed, and you can type a different name there. Read any yellow notes before you download.

4
Download and check

Set the file name and click Download merged .pl. Open it in PipeCAD and check the floors, detectors and results. The original files are never changed.

How the merge works

  • The design is copied unchanged. That includes every floor, detector, pipe run, sampling hole, end cap, T-piece, outline, label and saved PipeCAD result, with coordinates, hole sizes, fan speeds, alarm settings, flows and transport times.
  • Internal IDs. PipeCAD numbers each file's detectors, pipes and holes from 0, and the saved results point at those numbers. Each later file's numbers are moved up by one fixed amount, together with every results reference, so nothing collides and every result still belongs to the same pipe or hole. The project tree numbers move the same way.
  • File format. The merged file is written the way PipeCAD writes its own files: same XML header, indentation and Windows line endings. It is marked with the newest PipeCAD version among the inputs.

Naming rules

Only names that clash with a floor or detector in an earlier file change. Duplicate names inside one file are kept as the designer made them.

  • Detectors continue their own numbering at the same width: MASD 01 → MASD 05, MASD 1-2 → MASD 1-7. A name without a number gets one: Detector → Detector 2.
  • Floors keep their description. A trailing letter moves on (Area A → Area B). A simple word-and-number name counts up (Floor 1 → Floor 2). Anything else gets a copy number, so Pipes 1 & 4 becomes Pipes 1 & 4 (2).
  • Pipe names belong to their detector, so they never clash and never change.
  • You can type your own name in the Renamed table. It must not match any other floor or detector.

Project settings and which file goes first

A PipeCAD project has one set of project-wide settings. The merged file takes them from the first file in the list:

  • Project details: name, location, designer, company, address and contact.
  • Units, snap grid and view.
  • Pipe type: name, bore, outside diameter, stick length and part number.
  • Default options for new detectors. Existing detectors keep their own limits, hole sizes and sensitivity.

Put the file whose project details and pipe type you want to keep at the top.

Messages

Red: the merge is blocked
Different units. Set every project to the same units in PipeCAD and save again.
Different pipe bore or material. The airflow results depend on the bore, so these projects can't share one pipe type. Keep them as separate projects.
A name is already used. A name you typed in the Renamed table matches another floor or detector. Choose a different one.
Yellow: check before you download
Different stick length, OD or part number. Airflow is unchanged, but if PipeCAD recalculates, socket counts and part numbers follow the first file's pipe. Move a file to the top to keep its pipe type.
Different detector type. Each detector keeps its own type, but the project default changes.
Notes
These cover project details that were not carried over, ID shifts and the version stamp. They are for information only.

FAQs

Will the design or the calculated performance change?
No. Every value in every floor, detector, pipe, hole and saved result is copied exactly. Only internal ID numbers and clashing names change. Running tools/verify_merge.py from the repository on a merge checks this field by field.
Can I merge two revisions of the same project?
Yes. Matching floors and detectors from the later file are renamed, so you can compare them side by side in PipeCAD.
Can I merge a merged file again?
Yes. A merged file is an ordinary PipeCAD project, so you can add it to another merge.
Which PipeCAD versions work?
Files from PipeCAD 3.5.0.132 and 3.6.2.139 have been merged and opened in PipeCAD. Other 3.x files are likely to work. Open the result in PipeCAD to confirm.
Does it change my original files?
No. It only reads them and downloads a new file.
Can I use the merged file in the MASD Field Report?
Yes. Use Import PipeCAD (.pl) there. Each detector becomes one sheet, and the renamed detectors keep the sheets apart.

Install and privacy

This tool runs entirely in your browser. Files are read on this device and never uploaded. After the first visit it works offline. To install it as an app, use your browser's Install option (Chrome or Edge: the install icon in the address bar; Safari on iPhone or iPad: Share → Add to Home Screen). A Windows .exe version is planned.
